INSTALL
1. Extract one_vision_academy_full_system to C:\xampp\htdocs\
2. Rename it to one_vision_academy if needed.
3. Start Apache + MySQL in XAMPP.
4. Open phpMyAdmin.
5. Import/run database.sql.
6. Visit:
   http://localhost/one_vision_academy/
